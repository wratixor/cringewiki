# Публикация через Git

Файлы в `wiki/` — публичная, версионируемая часть Кринжевики. У каждой
Markdown-статьи обязателен блок с `id`, `title` и шестью целыми
`coordinates` от 1 до 10. Ссылки на Markdown-файлы автоматически становятся
связями карты после импорта.

После `git pull` на сервере запустите `python -m server.git_wiki` или
перезапустите службу: при запуске она импортирует Git-статьи. Посты, созданные
в веб-интерфейсе, живут отдельно в SQLite и этот импорт их не перезаписывает.
